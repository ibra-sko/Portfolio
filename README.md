# Ibrahim Sako — Freelance Landing Page

Landing page portfolio freelance en Next.js, responsive et animée.

## Stack
- Next.js 16
- React
- TypeScript
- Motion
- Lucide React

## Lancer le projet
```bash
npm install
npm run dev
```

Puis ouvrir http://localhost:3000.

## À personnaliser
Dans `components/landing-page.tsx` :
- remplacer `ton-email@example.com` par ton email professionnel ;
- remplacer le lien LinkedIn (`href="#"`) ;
- ajouter les vraies captures / liens de projets si souhaité.

## Positionnement
La landing met l'accent sur les projets et le produit, avec Polewin présenté comme une application React Native + Express + TypeScript.
